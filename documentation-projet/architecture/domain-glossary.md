# Glossaire de domaine (Ubiquitous Language) — Proposition initiale

- Client: personne physique ou morale utilisant la plateforme.
- Compte: entité financière rattachée à un Client (peut avoir plusieurs comptes).
- Portefeuille / Wallet: ensemble de positions et soldes sur un compte.
- Ordre: instruction d'acheter ou vendre un instrument (market, limit).
- Position: quantité détenue d'un instrument (symbole) pour un compte.
- Trade / Fill: exécution partielle ou complète d'un ordre.
- Ledger / Journal: enregistrement append-only de mouvements financiers (dépôts, retraits, trades).
- KYC: Know Your Customer — processus de vérification documentaire.
- OTP: One-Time Password — code d'activation ou MFA.
- MFA: Multi-Factor Authentication — facteur secondaire d'authentification.
- Idempotency-Key: clé fournie par le client pour garantir l'idempotence d'une opération (ex: dépôt).
- Audit: journal interne immuable des actions critiques (append-only).
- Pre-trade validation: règles exécutées avant l'acceptation d'un ordre (solde suffisant, limites, compliance).
